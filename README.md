# 🎓 RAG Campus Assistant

> 基于 **COSMO Code** 平台的校园智能问答助手 —— 能拆分复合问题、答案可溯源、答不出就诚实说。

面向校园场景的 RAG（检索增强生成）问答应用：学生用**自然语言或语音**提问，系统从 11 份校园官方文档中检索、重排并生成答案，**并标注来源**。

---

## 📖 为什么做它

校园信息分散在 10+ 份官方文档里——查"转专业条件"要翻《教学指南》，查"食堂几点开门"要翻《生活指南》，**一条信息平均要翻 3-5 份文档**。

- 通用大模型（ChatGPT/千问/豆包）：对校园专属信息**编造或答"不知道"**
- 传统关键词搜索：只返回零散片段，遇到**复合问题**束手无策

**RAG Campus Assistant 把"翻文档"变成"问一句"。**

---

## ✨ 核心亮点（和普通 RAG 的不同）

| 普通 RAG | RAG Campus Assistant |
|---|---|
| 一次只答**一个**问题 | **复合问题拆分**：多个子问题分别检索、分点作答 |
| 检索不到也硬编 | **答不出就说"未找到"，绝不编造** |
| 一次检索定结果 | **ReAct 多步推理**：信息不足自动改写重查 |
| 做完不知道好坏 | **内置 RAGAS 自评测**：质量有数据 |

外加：**语音提问**（多模态输入）、**流式打字机**输出、答案去重。

---

## 🧠 感知-推理-决策

- **感知** —— 理解问题意图，判断单一/复合问题
- **推理** —— 检索 → 重排序 → 必要时多步推理（ReAct）
- **决策** —— 生成答案并标注来源；检索不到时如实说明

## 🏗️ 技术架构

```
┌─────────────┐     ┌──────────────────────┐     ┌──────────────┐
│  前端界面    │ ←→  │   平台内后端 RAG      │ ←→  │  11 份知识库  │
```

**前端、后端、知识库三者都在 COSMO Code 平台内运行。**

## 🚀 快速开始

### 方式一：在 COSMO Code 平台运行（推荐）

1. 在 COSMO Code 中创建任务，通过自然语言描述生成/导入本项目
2. 将 `data/` 目录下的 11 份文档 + `metadata.json` 放入项目数据目录
3. 配置守护进程（`start.sh`，端口 3001），启动服务
4. 访问平台分配的预览地址，即可使用

### 方式二：本地运行

```bash
# 安装依赖
npm install

# 配置大模型（默认用平台内置模型；本地运行需自备 OpenAI 兼容 API）
cp .env.example .env
# 编辑 .env：
#   LLM_BASE_URL=https://api.deepseek.com/v1
#   LLM_API_KEY=sk-xxx
#   LLM_MODEL=deepseek-chat

# 构建前端 + 启动服务（监听 3001）
npm start
```

访问 `http://localhost:3001` 即可。

## 📁 项目结构

```
.
├── backend/               # 后端（Node/Express）
│   ├── server.js          # 入口：接口路由 + 静态托管
│   ├── rag.js             # 检索：切片 + 召回 + 重排
│   ├── llm.js             # 大模型调用
│   ├── config.js          # 配置（平台内置模型优先）
│   ├── qa.js              # 问答编排
│   ├── split.js           # 复合问题拆分（Query Rewriting）
│   ├── cleanup.js         # 答案去重
│   └── eval.js            # 自动化测评（RAGAS 指标）
├── frontend/              # 前端（React + Vite）
├── data/                  # 校园知识库（11 份文档 + metadata.json）
├── scripts/ensure-build.js
├── start.sh / stop.sh     # 启动/停止脚本
└── package.json
```
